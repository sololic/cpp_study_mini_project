# 연산자 심화 (Operators Advanced)

## 📖 정수 나눗셈 — 소수점이 버려진다

```cpp
int x = 7, y = 2;
std::cout << x / y;          // 3  (소수점 버림!)
std::cout << (double)x / y;  // 3.5
```

| | C++ | Python |
|---|---|---|
| `7 / 2` | `3` (정수 나눗셈) | `3.5` (자동 float) |
| `7 // 2` | 없음 | `3` (명시적 정수 나눗셈) |

> C++에서 실수 나눗셈이 필요하면 한쪽을 `double`로 캐스팅해야 한다.

### 음수 나눗셈 — C++과 Python의 차이

C++은 **0 방향으로 버림(truncation toward zero)**, Python `//`은 **내림(floor toward -∞)**.

```cpp
// C++
-7 / 2   // -3  (0 방향: -3.5에서 0 쪽으로 버림)
7 / -2   // -3
-7 / -2  //  3
```

```python
# Python
-7 // 2   # -4  (내림: -3.5에서 -∞ 쪽으로 버림)
7 // -2   # -4
-7 // -2  #  3
```

| 식 | C++ 결과 | Python `//` 결과 |
|----|:--------:|:----------------:|
| `-7 / 2` | `-3` | `-4` |
| `7 / -2` | `-3` | `-4` |
| `-7 / -2` | `3` | `3` |

> **핵심 차이**: `-3.5`에서 C++은 0에 가까운 `-3`, Python은 더 작은 `-4`를 선택한다.

## 📖 `++` / `--` — 전위 vs 후위

```cpp
// 전위(prefix): 먼저 증가 후 사용
int a = 5;
std::cout << ++a;  // 6 출력, a = 6

// 후위(postfix): 먼저 사용 후 증가
int b = 5;
std::cout << b++;  // 5 출력, b = 6 (출력 후 증가)
```

| | 전위 `++x` | 후위 `x++` |
|---|---|---|
| 동작 | 증가 → 사용 | 사용 → 증가 |
| 단독 사용 | 차이 없음 | 차이 없음 |
| 표현식 안에서 | 증가된 값 | 원래 값 |

> Python에는 `++` / `--` 연산자가 없다. `x += 1`로 대신한다.

## 📖 음수 저장 방식 — 두 보수 (Two's Complement)

비트 연산을 이해하려면 C++이 음수를 어떻게 저장하는지 알아야 한다.

### 왜 `-` 기호로 저장 못 하나?

컴퓨터는 0과 1만 저장할 수 있어서 `-` 기호를 저장할 수 없다.  
**비트만으로 음수를 표현하는 규칙**이 필요하다.

### 방법 1 — 부호-크기 (직관적이지만 문제 있음)

```
+2 = 0 010  (부호 0, 크기 010)
-2 = 1 010  (부호 1, 크기 010)
```

문제: `+0 = 0000`, `-0 = 1000` → **0이 두 개 생김**  
덧셈도 깨짐:
```
  0000 0011  (+3)
+ 1000 0011  (-3, 부호-크기)
= 1000 0110  = -6  ← 0이 아님!
```

### 방법 2 — 두 보수 (C++이 실제로 쓰는 방식)

**음수 만드는 규칙: 반전 후 +1**

```
+2 = 0000 0010
      ↓ 반전
     1111 1101
      ↓ +1
-2 = 1111 1110
```

**왜 +1을 하나?** → 0이 두 개 생기는 걸 막기 위해

```
+0 = 0000 0000 → 반전 → 1111 1111 → +1 → 0000 0000  (자리올림 넘쳐서 0 하나만)
```

덧셈도 정상 작동:
```
  0000 0011  (+3)
+ 1111 1101  (-3, 두 보수)
= 0000 0000  = 0  ✓
```

> **덧셈 회로 하나로 뺄셈까지 되게 하려고.** 하드웨어를 단순하게 만들기 위한 선택이다.

### int(signed) 읽는 규칙

| 맨 앞 비트 | 의미 | 읽는 방법 |
|:---:|---|---|
| `0` | 양수 | 그냥 읽기 |
| `1` | 음수 | 반전+1 해서 크기 구하고 `-` 붙이기 |

```
1111 1110  →  맨 앞 1 → 음수
              반전 → 0000 0001
              +1  → 0000 0010 = 2
              결과: -2
```

### unsigned vs int — 같은 비트, 다른 해석

비트는 동일하고, 타입이 의미를 부여한다.

```
1111 1110  →  unsigned int  →  254  (맨 앞 비트도 숫자로 읽기)
1111 1110  →  int           →  -2   (맨 앞 비트를 부호로 읽기)
```

```cpp
int          a = -2;   // 1111...1110 → -2로 해석
unsigned int b = 254;  // 1111...1110 → 254로 해석
```

## 📖 비트 연산자

비트 연산은 **정수를 2진수로 보고 각 비트를 직접 조작**하는 연산이다.

### 0b — 2진수 리터럴

`0b`는 **2진수(binary) 리터럴 접두사**다. C++14부터 지원.

```cpp
int flags = 0b1111;  // 2진수 1111 = 10진수 15
```

숫자 앞에 붙는 접두사 종류:

| 접두사 | 진법 | 예시 | 10진수 값 |
|--------|------|------|-----------|
| 없음 | 10진수 | `15` | 15 |
| `0b` | **2진수** | `0b1111` | 15 |
| `0x` | 16진수 | `0xF` | 15 |
| `0` | 8진수 | `017` | 15 |

비트 연산에서 `0b`를 쓰는 이유는 **어떤 비트가 켜져 있는지 눈으로 바로 보이기 때문**이다:

```cpp
int flags = 0b1010;  // 2번, 4번 비트 ON → 의도가 명확
int flags = 10;      // 10? 비트 의미가 바로 안 보임
```

```
0b1111  →  1  1  1  1
           8  4  2  1  ← 자릿값
           = 8+4+2+1 = 15
```

> Python도 `0b1111`로 동일하게 쓸 수 있다.

---

### 비트 연산자 종류

| 연산자 | 이름 | 설명 |
|--------|------|------|
| `&` | AND | 둘 다 1이면 1 |
| `\|` | OR | 하나라도 1이면 1 |
| `^` | XOR | 다르면 1, 같으면 0 |
| `~` | NOT | 비트 반전 |
| `<<` | 왼쪽 시프트 | 비트를 왼쪽으로 이동 (×2 효과) |
| `>>` | 오른쪽 시프트 | 비트를 오른쪽으로 이동 (÷2 효과) |

```cpp
int a = 0b1010;  // 10
int b = 0b1100;  // 12

a & b   // 0b1000 = 8   (AND: 둘 다 1인 자리만)
a | b   // 0b1110 = 14  (OR:  하나라도 1인 자리)
a ^ b   // 0b0110 = 6   (XOR: 다른 자리만 1)
~a      // -11           (NOT: 모든 비트 반전)
a << 1  // 0b10100 = 20 (×2)
a >> 1  // 0b0101  = 5  (÷2)
```

### 맨 앞 비트(부호 비트) 읽는 법

| 맨 앞 비트 | 의미 | 읽는 방법 |
|:----------:|------|-----------|
| `0` | 양수 | 그냥 읽기 |
| `1` | 음수 | 반전+1 해서 크기 구하고 `-` 붙이기 |

### `~a` — 비트 NOT 상세

`~a`는 **모든 비트를 반전**시킨다. 부호 비트까지 포함해서 반전된다.

**양수일 때 (a = 10):**
```
+10 = 0000 1010
       ↓ 전체 반전
      1111 0101  →  맨 앞 1 → 음수
                    반전+1 → 0000 1010+1 = 0000 1011 = 11
                    결과: -11
```

**음수일 때 (a = -10):**
```
-10 저장:  0000 1010 → 반전 → 1111 0101 → +1 → 1111 0110
~(-10):    1111 0110
            ↓ 전체 반전
           0000 1001  →  맨 앞 0 → 양수 → 그냥 읽기 → 9
```

**공식으로 기억하기:**
```
~a = -(a + 1)

~10  = -(10 + 1)  = -11
~-10 = -(-10 + 1) = -(-9) = 9
~0   = -(0 + 1)   = -1
~-1  = -(-1 + 1)  = 0
```

> `~`는 비트를 뒤집는 것이고, 공식 `~a = -(a+1)`로 결과를 바로 계산할 수 있다.

### 🔧 실전 활용 — 센서 플래그

비트 연산은 **여러 상태를 하나의 정수에 압축**해서 저장할 때 쓴다.

```cpp
// 각 비트가 하나의 센서 상태를 나타냄
const int SENSOR_A = 0b0001;  // 1번 비트
const int SENSOR_B = 0b0010;  // 2번 비트
const int SENSOR_C = 0b0100;  // 3번 비트
const int SENSOR_D = 0b1000;  // 4번 비트

int flags = 0b1010;  // B, D 센서만 활성화

if (flags & SENSOR_B) { /* B 센서 켜짐 */ }  // AND로 특정 비트 확인
flags |= SENSOR_A;   // A 센서 켜기 (OR로 비트 세팅)
flags &= ~SENSOR_B;  // B 센서 끄기 (NOT + AND로 특정 비트만 0으로)
```

> Python도 동일하게 비트 연산자를 쓴다. `0b` 접두사도 동일.
