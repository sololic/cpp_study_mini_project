## 학습 단계

### 1단계 — 복습 (`review/`)

week1에서 헷갈렸던 개념 다시 잡기.

| 주제 | week1 학습 내용 | 목표 수준 |
|------|----------------|-----------|
| 참조 (`&`) | 별명(alias), 함수 참조 매개변수 | 안 보고 쓸 수 있는 수준 |
| 포인터 (`*`) | 주소 저장, 역참조, nullptr | 개념부터 다시, 확실히 이해 |
| 동적배열 (`std::vector`) | push_back, size, range-for | 실전 활용 가능한 수준 |
