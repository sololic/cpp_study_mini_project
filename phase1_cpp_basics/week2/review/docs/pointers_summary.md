# 포인터 (Pointer) 정리

---

## ⚠️ Python과의 비교

> **Python에는 포인터가 없다.**  
> Python은 모든 변수가 내부적으로 객체를 참조하는 방식으로 동작하지만,  
> 개발자가 메모리 주소를 직접 다루는 포인터 문법은 제공하지 않는다.
>
> C++에서 포인터가 필요한 이유:
> - 메모리를 직접 제어해야 할 때 (임베디드, 로보틱스)
> - 동적 메모리 할당 (`new`, `delete`)
> - ROS2의 스마트 포인터 (`shared_ptr`, `unique_ptr`) 이해를 위한 기초

---

## 📌 포인터란?

변수의 **메모리 주소를 저장하는 변수**다.

```cpp
int val = 42;
int* ptr = &val;   // ptr에 val의 주소 저장
```

### 집으로 비유하면

| 개념 | 비유 |
|------|------|
| `val` | 집 (물건 + 주소 둘 다 가짐) |
| `val` 안의 값 (`42`) | 집 안의 물건 |
| `&val` | 집 주소를 **가져오는** 연산자 |
| `ptr` | 집 주소가 적힌 메모지 |
| `*ptr` | 메모지 보고 집 찾아가서 물건 꺼내기 (역참조) |

---

## 📖 기본 문법

```cpp
int val = 42;
int* ptr = &val;    // ptr에 val의 주소 저장

// 출력
val          // 42   (값)
&val         // 0x7fff... (주소)
ptr          // 0x7fff... (&val과 동일)
*ptr         // 42   (역참조: ptr이 가리키는 값)

// 역참조로 값 변경
*ptr = 100;  // val == 100
```

> `&` = 주소를 **가져오는** 연산자 (주소 그 자체가 아님)  
> `*` = 주소가 가리키는 값을 **꺼내는** 연산자 (역참조)

---

## 📖 값 변경 vs 주소 변경

```cpp
int a = 10, b = 20;
int* ptr = &a;

// 값만 변경 → 주소는 그대로
*ptr = 99;     // a == 99, ptr의 주소는 변화 없음

// 다른 변수를 가리킴 → 주소 변경
ptr = &b;      // 이제 ptr은 b의 주소를 저장
```

## 📖 nullptr

아무것도 가리키지 않는 포인터.

```cpp
int* ptr = nullptr;   // 초기값으로 nullptr 권장

// nullptr 역참조 → 프로그램 크래시 (Segmentation fault)
// *ptr = 10;  // 위험!

// 사용 전 반드시 체크
if (ptr != nullptr) {
    std::cout << *ptr;
}
```

> 포인터는 사용 전 **반드시 nullptr 체크** 하는 습관이 중요하다.

## 📖 const 포인터

`*` 기준으로 `const` 위치에 따라 의미가 달라진다.

```cpp
const int* ptr   // * 왼쪽 const → 값 변경 불가, 주소 변경 가능
int* const ptr   // * 오른쪽 const → 주소 변경 불가, 값 변경 가능
const int* const ptr  // 둘 다 const → 둘 다 불가
```

| 선언 | 값 변경 | 주소 변경 |
|:----:|:-------:|:--------:|
| `const int* ptr` | ❌ | ✅ |
| `int* const ptr` | ✅ | ❌ |
| `const int* const ptr` | ❌ | ❌ |

```cpp
int a = 10, b = 20;

const int* p1 = &a;
// *p1 = 99;  // 에러! 값 변경 불가
p1 = &b;      // OK: 주소 변경 가능

int* const p2 = &a;
*p2 = 99;     // OK: 값 변경 가능
// p2 = &b;   // 에러! 주소 변경 불가
```

## 🔧 실전 활용

### 1. 동적 메모리 할당

```cpp
// 프로그램 실행 중에 필요한 만큼 메모리를 직접 할당
int* arr = new int[100];   // 힙에 int 100개 할당
arr[0] = 42;
delete[] arr;              // 사용 후 반드시 해제 (안 하면 메모리 누수)
```

> 로보틱스에서 센서 데이터 버퍼, 맵 데이터 등을 동적으로 관리할 때 사용.  
> 현대 C++에서는 `new/delete` 대신 **스마트 포인터**(`unique_ptr`, `shared_ptr`)를 쓴다.

### 2. ROS2 스마트 포인터 (포인터 이해가 기초)

```cpp
// ROS2 노드에서 가장 많이 보이는 패턴
auto node = std::make_shared<rclcpp::Node>("my_node");
//          ↑ shared_ptr: 포인터 개념을 안전하게 감싼 것
```

> `shared_ptr`은 포인터를 직접 쓰지 않아도 되게 해주지만,
> **포인터 개념(주소, 역참조)을 모르면 이해하기 어렵다.**

### 3. 연결 리스트 / 트리 구조

```cpp
// 로봇 경로 계획(Path Planning)에서 쓰는 트리 노드
struct TreeNode {
    int value;
    TreeNode* left;   // 왼쪽 자식을 가리키는 포인터
    TreeNode* right;  // 오른쪽 자식을 가리키는 포인터
};
```

### 4. 배열 순회 (C 스타일, 레거시 코드에서 자주 등장)

```cpp
int arr[] = {1, 2, 3, 4, 5};
int* ptr = arr;          // 배열의 첫 번째 주소

for (int i = 0; i < 5; i++) {
    std::cout << *ptr << " ";
    ptr++;               // 다음 요소로 이동
}
```

## 📖 Python id() vs C++ 주소

Python에서 `id()`로 객체의 메모리 주소를 볼 수 있다.  
C++의 `&` 연산자와 유사하지만, Python에서는 그 주소로 직접 접근하거나 조작할 수 없다.

```python
# Python
a = 10
print(id(a))   # 메모리 주소 출력 (조작 불가)
```

```cpp
// C++
int a = 10;
std::cout << &a;   // 메모리 주소 출력
int* ptr = &a;     // 그 주소를 저장하고 직접 조작 가능
*ptr = 99;         // 주소를 통해 값 변경
```

## 📊 포인터 vs 참조 비교

| | 포인터 (`int*`) | 참조 (`int&`) |
|--|:--------------:|:------------:|
| 초기화 | 나중에 가능 | 선언과 동시에 필수 |
| 재지정 | ✅ 가능 | ❌ 불가 |
| nullptr | ✅ 가능 | ❌ 없음 |
| 문법 | `*ptr = val` | `ref = val` |
| 용도 | 주소 저장·조작 | 안전한 별명 |

> 단순히 변수를 함수에서 수정하고 싶을 때 → **참조**  
> 주소 자체를 다루거나 nullptr 가능성이 있을 때 → **포인터**
